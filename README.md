# MA Research Radar — Public Version

Browse recent papers from top management accounting journals.
No login, no API key, no installation needed.

## Deploy to Streamlit Community Cloud (free)

1. Push this folder to a GitHub repository
2. Go to https://share.streamlit.io
3. Sign in with GitHub → New app → select your repo
4. Set the main file to `app.py` and click Deploy
5. Share the URL with colleagues

## Run locally

```
pip install -r requirements.txt
streamlit run app.py
```
